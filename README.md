# מרכז המדריכים 📚 — גרסה 2 (העלאה דרך הצ'אט)

צ'אט מקומי בעברית שמעלים אליו מדריכים ושואלים עליהם. מחובר ל-Google Gemini.
אפס NuGet. **ה-HTML מוטמע בתוך התוכנה** — אין יותר "index.html לא נמצא".

## מה חדש בגרסה הזו
- ➕ **העלאת מדריכים ישר בצ'אט** — כפתור "העלה מדריך" או פשוט **גרירה** של קבצים לחלון.
- הקובץ מאונדקס אוטומטית ומיד אפשר לשאול עליו. אין צורך ב-ingest ידני.
- ה-HTML מובנה בתוך ה-exe.

## הפעלה (3 שלבים)
1. **מפתח Gemini** (חינם): https://aistudio.google.com/apikey → Create API key.
   צור קובץ `.env`:
   ```
   GEMINI_API_KEY=AIza...
   ```
2. **בנה והרץ:**
   ```
   dotnet build -c Release
   dotnet run -- serve
   ```
3. פתח **http://127.0.0.1:5000/** — גרור מדריכים לצ'אט ותתחיל לשאול.

> השאר את חלון הפקודה פתוח כל עוד אתה משתמש — הוא השרת.

## נתמך להעלאה
Word (.docx) · תמונות (.png/.jpg/.webp) · טקסט (.txt/.md) · PDF (חלקי).
צילומי מסך מתוארים אוטומטית ע"י Gemini vision ("איפה ללחוץ").

## אם embeddings נכשל
הוסף ל-`.env`:  `EMBED_MODEL=text-embedding-004`

## פרטיות
תוכן המדריכים נשלח ל-Google (Gemini). למדריכים פנימיים רגישים — ודא שמאושר.
